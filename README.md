# Beatriz Victa — Portfolio

Responsive, animated one-page portfolio in plain HTML, CSS and JavaScript. No paid hosting or build tools required.

## Publish free with GitHub Pages

1. Sign in at https://github.com.
2. Create a **public** repository named exactly `beattus.github.io` (the GitHub username shown in the supplied CV is `beattus`).
3. Upload `index.html`, `logo.svg` and `favicon.svg` to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then Save.
7. After GitHub finishes publishing, open `https://beattus.github.io`.

If the GitHub username differs or that repository name is unavailable, create any repository and enable Pages from `main` / root. The URL will be `https://USERNAME.github.io/REPOSITORY/`.

## Customize
Edit `index.html` to change text, links, sections or CSS colors. The page respects `prefers-reduced-motion`. Google Fonts load online; system fonts are used as fallback.
